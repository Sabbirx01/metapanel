Key যোগ করার ১-৩ মিনিট পরে GitHub Pages-এ দেখা যায় (Pages build time)। এর আগে customer key দিলে পেজটা নিজেই সরাসরি GitHub থেকে নতুন তালিকা পড়ে নেয় — তাই সাথে সাথেই কাজ করবে।

⚙️ নিয়ম ও সতর্কতা

• key = customer-এর licence key (licence server-এর «Metav2 client setup» থেকে generate করা, format METAV2-XXXXX-XXXXX-XXXXXXXX). এখানে বসালে শুধু hash জমা হয় — key কখনো plain-text-এ কোথাও যায় না, তাই তালিকা public হলেও নিরাপদ।
• একই key আবার দিলে সেটা নতুন করে যোগ হয় না — আগেরটা approve হয়ে যায় (নাম বদলাতে চাইলে আগে Remove, তারপর আবার Add)।
• ❌ কেউ share করলে: সেই key Block করুন → সাথে সাথে download বন্ধ। আবার চালু করতে Unblock।
• ⚠️ token কখনো কারও সাথে share করবেন না, screenshot-এ যেন না ওঠে। লিক হলে GitHub-এ ওই token revoke করে নতুন বানান।
• download গেটটা নরম (ফাইল release-এ public) — আসল তালা licence: key এক PC-তে bind হয়, অন্যের PC-তে অ্যাপ চালু হবে না।
